Wedding Invitation Landing Page
===============================

Files included:
- index.html
- styles.css
- script.js
- assets/images/*

How to use:
1. Keep all files in the same folder structure.
2. Open index.html in a browser to preview.
3. Upload the whole folder to GitHub Pages, Netlify, Vercel, or any static web host.

Current configuration:
- Couple: Timothy & Namfa
- Wedding date/time: November 21, 2026, 4:00 PM UTC+7
- Venue: Saint Phila Convention Center - Hall D
- Map button: linked to the provided Google Maps URL
- Music button: opens embedded YouTube player for 'Beautiful in White'
- Languages: English and Lao
- Countdown: fixed bottom center

If you want to edit text later, open index.html and modify the visible content.
If you want to swap photos later, replace the files in assets/images and keep the same filenames.
